# Design Context — JobFinder

## Target Audience
Tech professionals (developers, engineers, data scientists) actively job hunting. Comfortable with automation, filters, and analytics dashboards. Remote-first, multilingual (EN/UA/ES). Privacy-conscious — prefer self-hosted over SaaS.

## Use Cases
- Configuring automated job searches across 11 platforms (LinkedIn, Indeed, etc.)
- Reviewing and scoring vacancies with AI match percentage
- Tracking application pipeline (New → Applied → Response → Interview → Offer/Reject)
- Analyzing job search funnel and trends
- Auto-applying to matched positions (Playwright headless)
- Managing recruiter email responses

## Brand Personality / Tone
**Professional productivity tool.** Clean, efficient, confidence-inspiring. The UI should make job hunting feel organized and systematic rather than stressful. Dark-mode-first with a modern tech aesthetic. Gold accents (#FFC700) on landing page convey premium/ambition; dashboard itself is neutral blue for focus.

## Visual Identity

### Colors
- **Primary:** #2563eb (blue-600) / #3b82f6 (dark mode)
- **Landing accent:** #FFC700 (gold/yellow) — premium feel
- **Background:** #f8fafc (light) / #0a0f1a (dark)
- **Cards:** #ffffff (light) / rgba(255,255,255,0.04) (dark)
- **Semantic:** green (#059669) positive metrics, red (#dc2626) rejections, amber (#d97706) pending

### Typography
- **Font:** Inter (Latin + Cyrillic)
- **Style:** semibold headings, medium body, antialiased

### Components
- shadcn/ui + Radix UI + Tailwind CSS 4
- Lucide icons, Recharts charts, Sonner toasts
- Dark/light mode via next-themes + alternative skins (Aurora, Taras)

### Patterns
- Sidebar navigation with active state indicators
- Card-based vacancy display with score badges
- Funnel charts for application pipeline analytics
- Filter panels (platform, score slider, status)
- Mobile-optimized swipe interface for vacancies
- Bottom navigation bar on mobile
- Data tables for applications tracking

## Anti-Patterns to Avoid
- Overly casual or motivational copy — users are stressed enough
- Complex onboarding flows that delay first value
- Decorative illustrations instead of functional UI
- Aggressive color coding — subtle semantic colors only
- Cluttered filter UIs — progressive disclosure preferred
